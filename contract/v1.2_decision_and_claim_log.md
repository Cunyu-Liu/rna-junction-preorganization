## 1. 最终决策

v1.2 采用 **tectoRNA-first** 路线，并将 target-specific thermodynamic functional 设为唯一主 estimand。当前 7,500-construct DMS 在本版本中永久不准入正式标签、模型、split、阈值、效果量或科学 benchmark；历史 RNA-MAP replay 仅保留为工程证据。

qMaPseq 被锁定为：

> 强论文路线必须完成的第二系统审计与迁移测试；不要求得到阳性结果，不阻塞 tecto 主线，也不作为 junction preorganization 的同标签独立复现。

当前没有科学解锁，也没有发表保证。当前只授权 tecto T0 数据准入审计与 qMaPseq Q0–Q3 并行准备；任何真实 tecto 标签建模必须等待 T0、S0、T1、M0 依次通过。

## 4. DAG 与授权边界

### tecto 主线

`T0 data admission → S0 estimand/operator/symmetry freeze → T1 cleaning/QC/effective-N/split freeze → M0 synthetic/operator-identification tests → T2 tecto-only inference → T3 target-specific functional → optional sequence-only deployment → manuscript adjudication`

### qMaPseq 第二系统

`Q0 integrity/license freeze → Q1 98-variant registry → Q2 attrition/censoring reconstruction → Q3 endpoint replay → Q4 selection/split/analysis freeze → Q5 locked transfer test → claim adjudication`

硬边界：

- T0–T3 不依赖 current DMS 或 qMaPseq。
- Q0–Q3 可与 tecto T0/S0/T1 并行。
- Q4/Q5 不得修改已冻结的 tecto estimand、operator、模型、阈值、split 或 primary metric。
- qMaPseq 只裁定跨 measurement system、chemical-mapping thermodynamics 或 generalization 主张，不是 tecto unlock gate。
- v1.2 不包含新湿实验、远端同步、训练或 GPU Gate。

## 5. qMaPseq completion 与 claim 边界

合同要求按公开证据逐项重建 98 个筛选 variants，并区分：84 个 fitted、11 个 `[Mg²⁺]1/2 > 40 mM` 右删失、2 个 closing-pair structural-QC 和 1 个 alternate/unknown structural-QC。84 个 complete cases 不得冒充完整无偏验证集；11 个删失样本必须进入 censored likelihood，后三个 structural-QC 样本必须进入预定义 sensitivity analysis。

| qMaP 终态 | 是否算完成 | 强论文路线与允许主张 |
|---|---:|---|
| `QMAP_TRANSFER_SUPPORTED` | 是 | 可写受限的跨 measurement-system 迁移支持；不得写 junction 同标签独立复现 |
| `QMAP_TRANSFER_NOT_SUPPORTED` | 是 | 可写预注册阴性/边界证据；主张降为 tecto-specific |
| `QMAP_INCONCLUSIVE` | 是 | 只允许不确定性与 power 边界叙述 |
| `QMAP_NOT_ADMITTED` | admission 分析终结 | 关闭强跨系统路线；tecto 主线可继续 |
| Q4/Q5 `FAIL/BLOCKED/NOT_STARTED` 且 `NOT_ADJUDICATED` | 否 | fail closed；Tecto PASS 最多 `TECTO_SPECIFIC`，Tecto FAIL 为 `STOP_MECHANISM_ROUTE` |

## 6. 论文主张矩阵摘要

| 结果组合 | 最多允许的论文定位 |
|---|---|
| Tecto PASS + `QMAP_TRANSFER_SUPPORTED` | 受限的跨 measurement-system 方法与迁移结果 |
| Tecto PASS + `QMAP_TRANSFER_NOT_SUPPORTED` / `QMAP_INCONCLUSIVE` | tecto-specific operator-robust/partial-identification 方法；qMaP 为边界证据 |
| Tecto PASS + `QMAP_NOT_ADMITTED` | tecto-specific reanalysis、benchmark 或 partial-ID case study |
| Tecto PASS + qMaP mandatory Gate 未完成 | `TECTO_SPECIFIC`，必须披露 Gate 未完成；不得写 qMaP completed |
| Tecto FAIL + qMaP supported | measurement/identifiability comparative result；不得保留 junction-preorganization 主标题 |
| Tecto FAIL + qMaP 未完成，或两支均无可解释结果 | `STOP_MECHANISM_ROUTE`；数据审计稿是否有独立价值需新合同裁定 |

永久禁止的代表性表述包括：“当前 7,500-construct DMS 验证了 tectoRNA”“DMS 普遍等价于 thermodynamic ΔG”“qMaPseq 独立复现 junction preorganization”“Bonilla/Shin/Yesselman 是三套独立外部验证”“负结果或合同完成保证发表”。
